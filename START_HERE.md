## 🎯 Key Concepts (TL;DR)

### Strategies
Create rules that generate trading signals automatically.
6 types available: RSI, MACD, Bollinger Bands, Moving Average, Momentum, ATR

### Signals
BUY/SELL recommendations generated by your strategies.
Appear on dashboard and Signals page.

### Backtesting
Test strategies on historical data.
See win rates, P&L, and other metrics before going live.

### Trades
Actual executions based on signals.
Track in Portfolio page with P&L.

### Dashboard
Your command center showing signals, strategies, and stats.

Just want to try it now?

1. Go to Settings, add Zerodha credentials
2. Go to Strategies → Create Strategy
3. Use defaults, click Create
4. Check Dashboard for signals
