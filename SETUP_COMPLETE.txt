🎯 HOW TO GET STARTED
================================================================================

1. READ DOCUMENTATION
   Start with: START_HERE.md
   Options:
   - 5 minutes: QUICK_START.md
   - 20 minutes: README.md
   - Reference: STRATEGY_REFERENCE.md

2. CONFIGURE API
   - Go to Settings
   - Add Zerodha credentials
   - Or use mock mode

3. CREATE STRATEGY
   - Go to Strategies
   - Click "Create Strategy"
   - Select type (RSI recommended for beginners)
   - Use default parameters
   - Click Create

4. CHECK DASHBOARD
   - Go to Dashboard
   - Wait for next 5-minute scan
   - See signals appear

5. BACKTEST (optional)
   - Go to Backtest
   - Select your strategy
   - Set date range
   - See historical performance

6. TRADE
   - Click signal to create trade
   - Track in Portfolio
   - Monitor performance
