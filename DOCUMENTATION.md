## 🚀 Common Workflows

### Creating Your First Strategy
1. Go to **Strategies** page
2. Click **Create Strategy**
3. Fill in name and choose type
4. Configure parameters (use defaults to start)
5. Click **Create**
6. Check dashboard for signals

See [QUICK_START.md](QUICK_START.md) Step 2 for details.

### Testing Before Going Live
1. Go to **Backtest** page
2. Select your strategy
3. Choose a 6-month date range
4. Click **Run Backtest**
5. Review win rate and P&L
6. Adjust parameters if needed
7. Repeat until satisfied

See [README.md](README.md) > Backtesting section for details.

### Monitoring Your Signals
1. Dashboard shows recent signals automatically
2. Go to **Signals** for complete list
3. Click signal to see details
4. Click **Create Trade** to act on it
5. Check **Portfolio** to track performance

See [README.md](README.md) > Monitoring Signals section for details.

## 💡 Tips & Best Practices

### Getting Started
- Start with 1 strategy (RSI is easiest)
- Use default parameters first
- Backtest before going live
- Check dashboard daily

### Success Factors
- Write clear strategy descriptions
- Document why you're creating each strategy
- Add notes to trades explaining entries
- Review backtest results monthly
- Adjust parameters based on results

### Common Mistakes to Avoid
- Creating too many strategies at once
- Not backtesting before going live
- Using unrealistic parameters
- Ignoring signal strength
- Not monitoring performance

See [README.md](README.md) > Performance Tips for more.

## 📞 Support & Help

### If Something Isn't Working

1. **Check the docs**
   - [QUICK_START.md](QUICK_START.md) for basic issues
   - [README.md](README.md) > Troubleshooting for specific problems
   - [CHANGELOG.md](CHANGELOG.md) for recent changes

2. **Debug yourself**
   - Open browser console (F12)
   - Check error messages
   - Try refreshing the page
   - Clear browser cache

3. **Common Solutions**
   - Zerodha not working? Check Settings page
   - No signals? Check strategy is Active
   - Backtest failing? Use valid date range
   - Strategy creation failing? Fill all required fields
